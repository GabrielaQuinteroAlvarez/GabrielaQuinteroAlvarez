# PLC I/O & Industrial Controls Design

## Overview
This controls-focused design project demonstrates how industrial field devices can be organized around a PLC using digital and analog I/O.

## Example I/O Scope
- 12 digital inputs
- 12 digital outputs
- 6 analog inputs
- 4 analog outputs
- Industrial DC power supply
- START control
- RESET control
- Terminal blocks and connectors

## Design Tasks
- Organize PLC I/O
- Label field signals
- Separate digital and analog signals
- Document power distribution
- Plan terminal connections
- Create readable multi-sheet electrical drawings
- Maintain consistent device and wire identification

## Skills Demonstrated
- PLC I/O mapping
- Electrical schematic interpretation
- Industrial controls documentation
- Terminal-block planning
- Power distribution
- Digital vs. analog signal organization
- Design communication

## Why It Matters
Good controls engineering is not only about programming the PLC. The electrical documentation has to make the system understandable, buildable, testable, and maintainable for technicians and engineers.
