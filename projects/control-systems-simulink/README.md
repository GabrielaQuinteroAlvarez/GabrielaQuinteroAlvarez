# Control Systems Modeling with MATLAB & Simulink

## Overview
This control-systems project focuses on converting mathematical descriptions of physical systems into block-diagram models using **MATLAB and Simulink**.

## Work Completed
- Built Simulink block diagrams from system equations
- Used gain blocks for physical parameters
- Used summing junctions to represent force relationships
- Used integrators to obtain velocity and position
- Connected feedback paths
- Adjusted block orientation and signal flow
- Ran simulations and interpreted system behavior

## Concepts Applied
- Mathematical modeling
- Differential equations
- Transfer-function relationships
- Feedback
- Signal flow
- Dynamic-system response

## Why It Matters
Simulink makes it possible to take equations from control theory and turn them into a visual model that can be simulated and tested. This project helped me connect the mathematics of control systems with the behavior of an actual physical model.

## Tools
**MATLAB · Simulink · Control Systems**
