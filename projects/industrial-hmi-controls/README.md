# Industrial HMI & Controls Integration

## Overview
This page summarizes public-safe experience from my electrical engineering internship supporting **industrial power-generation and control-system projects**.

My work included hands-on exposure to HMIs, PLCs, industrial networking, control software, hardware configuration, and troubleshooting.

## Experience Areas
- HMI interface configuration and updates
- PLC/HMI communications
- Device IP configuration
- Loading control-system software and project files
- Industrial Ethernet communication
- Troubleshooting hardware/software integration
- Control-panel and field-device documentation
- Generator and turbine control-system concepts

## Platforms / Tools
- Horner PLC/HMI hardware
- Cscape
- AVEVA / InduSoft-style HMI environments
- Rockwell ControlLogix exposure
- Woodward control-system exposure
- Industrial Ethernet devices
- Windows-based engineering software

## Power-Generation Concepts
Through my internship, I gained exposure to:
- Automatic Voltage Regulators (AVRs)
- Governors
- Generator speed and frequency
- Voltage control
- Synchronization
- Breaker-closing sequence
- Droop
- Load sharing
- Generator-to-utility operation

## What I Learned
This experience helped connect classroom theory with real industrial systems. I learned how software, networking, electrical hardware, PLCs, HMIs, and rotating equipment interact inside a complete control system.
