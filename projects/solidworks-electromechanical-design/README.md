# SolidWorks Electromechanical Design

## Overview
This project page summarizes electromechanical CAD work completed while supporting industrial controls projects.

My work involved creating and editing parts, assemblies, cable assemblies, enclosure layouts, and engineering drawings that could be used for manufacturing and customer documentation.

## Work Completed
- Cable-assembly modeling
- Electrical connector placement
- Wire and cable routing
- Enclosure cutouts
- Door-panel component placement
- DIN-rail layouts
- Bottom and top mounting plates
- Multi-sheet engineering drawings
- BOM generation
- Balloon callouts
- Custom properties
- Part-number metadata
- Section views
- Isometric views
- Manufacturing dimensions

## Design Considerations
A major part of the work was making sure the CAD model could actually be manufactured and assembled. This included checking:
- Component clearances
- Mounting locations
- Cable routing
- Connector orientation
- Door-opening interference
- Fastener placement
- Cutout dimensions
