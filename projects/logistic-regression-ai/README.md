# Logistic Regression – Computational Foundations of AI

## Overview
This machine-learning coursework project explores **logistic regression** using Python.

The assignment focused on understanding how a classification model is trained, how predictions are generated, and how its performance can be evaluated.

## Work Included
- Preparing a two-feature dataset
- Training a logistic-regression classifier
- Generating predictions
- Calculating classification accuracy
- Examining model parameters
- Comparing results with scikit-learn's `LogisticRegression`

## Tools
- Python
- Jupyter Notebook
- NumPy
- scikit-learn

## Concepts
- Binary classification
- Logistic function
- Model coefficients
- Intercept
- Decision boundary
- Prediction
- Accuracy

## What I Learned
This project introduced me to the connection between the mathematical idea of a classifier and a practical machine-learning implementation.

It also gave me experience working in Jupyter Notebook and validating results using an established ML library.
